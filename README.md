# 🐍 Snake Game (Terminal)

Классическая Змейка в терминале на чистом Python + `curses`.

![Python](https://img.shields.io/badge/python-3.9%2B-blue)
![License](https://img.shields.io/badge/license-MIT-green)

## ✨ Возможности

- 🎮 Управление стрелками или WASD
- ⏸ Пауза (P) и рестарт (R)
- 🏆 Рекорд в текущей сессии
- 🎨 Цветной интерфейс
- 🧪 Покрыто тестами (pytest)

## 🚀 Установка

```bash
git clone https://github.com/your-username/snake-game.git
cd snake-game
pip install -r requirements.txt
```

## ▶️ Запуск

```bash
python snake.py
```

На Windows: `pip install windows-curses` (уже в requirements).

## 🎯 Управление

| Клавиша | Действие |
|---------|----------|
| ↑ ↓ ← → / WASD | Движение |
| P | Пауза |
| R | Рестарт (после Game Over) |
| Q | Выход |

## 🧪 Тесты

```bash
pytest -v
```
